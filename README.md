# Cryndel Launcher

**Удобный лаунчер Minecraft с профилями сборок, модами, настройкой внешнего вида и полезными инструментами для игры.**

[GitHub](https://github.com/Cryndel-tam/CryndelLauncher) · [Сайт проекта](https://ms.cryndel.ru) · [Подробная HTML-вики](https://ms.cryndel.ru/CL/wiki.html)

---

## О проекте

Cryndel Launcher — Это уникальный майнкрафт лаунчер для удобной игры в майнкрафт! Лаунчер создан для игроков Cryndel главное возможность лаунчера бесконечные расширенный и обсоляюно любой дизайн! Тут предусмотрено все: Качаете мод Лаунчер сам найдет и скачает зависимости, Сомневаетесь в моде лаунчер проверить его на безапастность, Нужно качать моды или зайти в My cryndel легко сделать в самом лаунчере : )
💘Мало функций не беда есть плагины для лаунчера! И много чего еще!

Приложение состоит из двух основных частей:

- **`electron/`** — главный процесс: запуск , работа с файлами, Java, игровыми профилями, загрузками, системными функциями и IPC.
- **`renderer/`** — интерфейс лаунчера: экраны, стили и клиентская логика.

В репозитории также есть `muzick/` с ресурсами проекта и подробной офлайн-вики. При Windows-сборке медиа из этой папки устанавливаются как внешние ресурсы; пользовательские треки и сгенерированные звуки сохраняются в доступной для записи папке данных лаунчера.

## Возможности

- **Игровые профили:** создание и управление отдельными сборками Minecraft.
- **Моды и Modrinth:** поиск и установка модов для выбранной сборки, работа с зависимостями и пакетами Modrinth.
- **Импорт сборок:** импорт поддерживаемых форматов, включая `.mpcryn` и `.mrpack`.
- **Java и запуск:** обнаружение Java, настройка памяти и параметров запуска игры.
- **Диагностика:** проверка состояния сборки, просмотр сведений о сбоях и доступные действия для восстановления.
- **Резервные копии:** создание снимков важных файлов и восстановление сборки.
- **Плагины:** управление расширениями и настройками плагинов через интерфейс лаунчера. ( также создавайте плагины для лаунчера )
- **Персонализация:** темы, собственный CSS, фон, интерфейсные звуки и фоновая музыка.
- **Инструменты игрока:** скриншоты, встроенный браузер и кабинет My Cryndel.
- **Информация в дискород** Пусть все увидят каким лаунчерам вы ползуетесь!
- **Отсутствия рекламы в лаунчере** - да там есть айпи нашего сервера новы можете легко скрыть в настройках или в коде.
- **Оптимизированный и настраиваемый** - Все елементы интерфейса анимации стили все можно настроить и оптимизировать!
- **От вашей милой команды** Cryndel team - известен своим замечательным майнкрафт серверам IP: Cryndel.ru!
- **Улучшение** -  обновление лаунчера будет выходит не часто но плагины новые будут. но и вы можете помоч нам оставив свое звезочку : )


Набор доступных функций может зависеть от версии приложения и состояния внешних сервисов.

## Быстрый старт

### Установка готовой версии

Откройте [cryndel.ru](https://my.cryndel.ru/launcher) и скачайте установщик для своей системы, если он доступен для текущего релиза.

### Запуск из исходного кода 

Требуется установленный Node.js и npm.

```bash
git clone https://github.com/Cryndel-tam/CryndelLauncher.git
cd CryndelLauncher
npm install
npm start
```

Для режима разработки:

```bash
npm run dev
```

Первый запуск может потребовать загрузки зависимостей npm. Для установки и запуска Minecraft также потребуется интернет-соединение и Java подходящей версии; лаунчер помогает определить или подготовить Java.

## Сборка приложения


Windows-установщик настроен на русский язык: он показывает лицензию MIT с подтверждением согласия, позволяет выбрать папку установки и использует значок проекта. Иконка `assets/icon.ico` встраивается в EXE средствами electron-builder; не отключайте обработку ресурсов EXE, иначе Windows может показать стандартную иконку Electron. Лицензия подключена в Unicode-совместимом RTF, чтобы русский текст правильно отображался в Windows. Исходный NSIS-файл находится в [`nsis/installer.nsh`](nsis/installer.nsh).

## Разработка и проверки

Запустить тесты:

```bash
npm test
```

Проверить основной код линтером:

```bash
npm run lint
```

Структура проекта:

```text
electron/       главный процесс, менеджеры, IPC и хранение данных
renderer/       интерфейс, экраны, стили и клиентский код
resources/      ресурсы приложения
assets/         ресурсы для сборщика
images/         изображения проекта
muzick/         медиафайлы и HTML-вики
tests/          автоматические тесты
```

При работе с интерфейсом проверяйте адаптивность: размеры окна могут меняться, поэтому новые экраны и стили должны корректно выглядеть и на узкой ширине.
